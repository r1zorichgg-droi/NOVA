# NOVA 1.05.8 — Required Update Policy

- Убрано редактируемое поле технического URL манифеста из интерфейса.
- В интерфейсе явно указан официальный канал NOVA Project · GitHub Releases.
- Проверка обязательна при запуске и повторяется каждый час, пока NOVA работает.
- При обнаружении новой версии загрузка начинается автоматически.
- После проверки SHA-256 пользователь должен установить обновление или закрыть NOVA.
- Автозапуск NOVA вместе с Windows выбран по умолчанию в Inno Setup, чтобы проверка выполнялась после входа.
- Сетевые ошибки не блокируют запуск без подтверждённого обновления; проверка повторяется позже.
- Пользовательские данные в %APPDATA%\NOVA остаются отдельно от файлов приложения.
