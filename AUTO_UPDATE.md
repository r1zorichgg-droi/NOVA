# NOVA Auto Update и Inno Setup

Репозиторий проекта: https://github.com/r1zorichgg-droi/NOVA
Канал обновлений: https://github.com/r1zorichgg-droi/NOVA/releases/latest/download/latest.json

## Сборка установщика на Windows

Требуется Windows 10/11 x64, Python 3.13 x64 и Inno Setup 6.

1. Запусти `build_installer.bat` из корня проекта.
2. Скрипт соберёт `dist\NOVA.exe`, синхронизирует номер версии из `config.py`, скомпилирует `installer\NOVA.iss` и создаст файлы в `release\`:
   - `NOVA.exe` — приложение;
   - `NOVA_Setup_[APP_VERSION].exe` — установщик;
   - `latest.json` — манифест автообновления.

Можно собрать вручную через Inno Setup Compiler:
1. Запусти `build\build_exe.bat`.
2. Выполни `powershell -ExecutionPolicy Bypass -File build\sync_version.ps1`.
3. Открой `installer\NOVA.iss` в Inno Setup Compiler и нажми **Build → Compile** (F9).

## Как выпускаются обновления для всех пользователей

В `config.py` уже настроен постоянный адрес манифеста этого репозитория. В `installer\NOVA.iss` также указаны правильные ссылки NOVA. GitHub Actions собирает Windows EXE и Inno Setup на Windows runner.

### Выпустить следующую версию

1. Измени код программы.
2. В `config.py` увеличь только `APP_VERSION`, например `1.05.7` → `1.05.8`.
3. Обнови список изменений в README или changelog.
4. В GitHub Desktop создай коммит, у которого поле Summary начинается строго с `release:`, например:
   `release: NOVA 1.05.8`.
5. Нажми **Push origin**.

GitHub Actions автоматически:
- соберёт `NOVA.exe`;
- создаст установщик Inno Setup;
- рассчитает SHA-256;
- сформирует `latest.json` с версией, ссылкой на установщик и контрольной суммой;
- создаст GitHub Release с тегом `v1.05.8` и добавит туда установщик и `latest.json`.

Для обычных коммитов без префикса `release:` выполняется сборка и публикация GitHub Actions artifact, но публичный Release не создаётся.

### Что происходит у пользователей

Установленная NOVA обращается к постоянному адресу latest.json. Когда выходит более новая версия, она показывает уведомление. После подтверждения пользователя программа скачивает установщик, проверяет SHA-256 и запускает Inno Setup. На время обновления NOVA закрывается.

Пользовательская база, настройки, игровые профили и FPS History хранятся отдельно в `%APPDATA%\NOVA` и не удаляются при штатном обновлении.

### Важные правила

- Репозиторий должен оставаться публичным, чтобы все пользователи могли скачать манифест и релиз.
- Не меняй `AppId` в `installer\NOVA.iss` между версиями: это идентификатор существующей установки.
- Не меняй постоянный `UPDATE_MANIFEST_URL` в уже опубликованных сборках, если не переносишь канал обновлений.
- Пользователям старой сборки 1.05.6, в которой был шаблонный адрес обновления, нужно один раз вручную установить исправленную 1.05.7. После этого последующие версии будут находиться автоматически.
- Для доверенной раздачи подпиши EXE и установщик Authenticode-сертификатом. SHA-256 проверяет целостность скачанного файла относительно манифеста, но не заменяет цифровую подпись издателя.
- Windows EXE и установщик собираются на Windows или GitHub Actions Windows runner. Из Linux настоящий Windows installer не создаётся.
