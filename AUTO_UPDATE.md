# NOVA Auto Update и Inno Setup

Репозиторий проекта: https://github.com/r1zorichgg-droi/NOVA

## Как получают обновления

NOVA проверяет официальный канал релизов проекта при запуске и затем каждый час, пока приложение работает. В интерфейсе не показывается технический URL манифеста; канал обозначен как «NOVA Project · GitHub Releases».

Когда появляется новая версия, приложение автоматически загружает установщик по HTTPS и проверяет SHA-256. После загрузки пользователь видит обязательное окно: **«Установить и перезапустить»** или **«Выйти из NOVA»**. Продолжить работу на старой версии после обнаружения обновления нельзя. Если сеть недоступна, NOVA сообщает об ошибке и повторяет проверку при следующем старте или через час.

При установке есть задача автозапуска NOVA вместе с Windows, выбранная по умолчанию. Это позволяет приложению проверить обновления после входа в Windows. Пользователь может снять эту задачу в установщике или отключить автозапуск в Windows; без работающей NOVA сервер не может мгновенно отправить обновление на выключенный компьютер.

## Собрать установщик

Требуется Windows 10/11 x64, Python 3.13 x64 и Inno Setup 6.

1. Запусти `build_installer.bat` из корня проекта.
2. Скрипт соберёт `dist\NOVA.exe`, синхронизирует номер версии из `config.py`, скомпилирует `installer\NOVA.iss` и создаст файлы в `release\`:
   - `NOVA.exe`;
   - `NOVA_Setup_[APP_VERSION].exe`;
   - `latest.json`.

Для ручной сборки: `build\build_exe.bat`, затем `powershell -ExecutionPolicy Bypass -File build\sync_version.ps1`, открой `installer\NOVA.iss` в Inno Setup Compiler и нажми F9.

## Выпуск новой версии

1. Измени код и увеличь `APP_VERSION` в `config.py`.
2. Создай коммит в GitHub Desktop с Summary, начинающимся с `release:`, например `release: NOVA 1.05.9`.
3. Нажми **Push origin**.

GitHub Actions соберёт Windows EXE, установщик Inno Setup, манифест с SHA-256 и опубликует GitHub Release.

## Важные ограничения и прозрачность

- Обновления поставляются из публичного GitHub Releases репозитория NOVA Project.
- Программа не обновляется на выключенном ПК в реальном времени. Проверка выполняется при запуске NOVA и периодически, пока она работает.
- Пользователям NOVA 1.05.7 потребуется один раз вручную установить 1.05.8: в старой версии обновление только показывало уведомление и не блокировало работу. После установки 1.05.8 обязательная политика применяется к следующим версиям.
- Если пользователь не разрешает обновление, он может закрыть NOVA; программа не скрывает установку и не устанавливает файлы без уведомления.
- Пользовательские настройки, библиотека игр, профили и FPS History хранятся в `%APPDATA%\NOVA` и не удаляются штатным обновлением.
- Не меняй `AppId` в `installer\NOVA.iss` между версиями.
- Для подтверждения издателя рекомендуется подписывать EXE и установщик Authenticode-сертификатом; SHA-256 проверяет целостность файла, но не заменяет цифровую подпись.
