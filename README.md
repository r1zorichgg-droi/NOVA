# NOVA — лаунчер, центр управления ПК и Dynamic Island для Windows

Тёмное приложение на Python + PySide6: боковая панель, главная с живыми метриками, мониторинг ПК и собственный
**Dynamic Island** — чёрная капсула сверху по центру экрана с музыкой, показателями ПК и уведомлениями.

## Статус

| Этап | Что входит | Состояние |
|---|---|---|
| **1** | Архитектура, БД, главное окно, Главная, Мониторинг, Dynamic Island, Автоматизация (автозапуск), Настройки, трей, иконка, сборка EXE | готов |
| **2** | Библиотека игр и приложений (автопоиск + ручное добавление), карточки с иконками, «Запустить», меню «⋯», режим производительности при запуске игры, «Электропитание», «Оптимизация», вкладка «Приложения» в Dynamic Island, **«Выпиление»** (удаление программ Windows и Microsoft Store) | **готов (этот архив)** |
| 3 | Магазин-каталог, глобальные горячие клавиши, управление питанием ПК (сон/выключение) с подтверждением | запланирован |

> **Важно.** Код проверен компиляцией Python и 212 тестами логики/дымового теста. Проверить реальные системные
> действия, установку сторонних приложений и отображение поверх игр здесь нельзя (нет Windows-среды): поверхность Windows
> (powercfg, реестр, Steam/Epic, меню «Пуск») проверена на имитациях. Поэтому **первый запуск на вашем ПК — это и есть
> первая проверка отрисовки и работы с настоящей системой**. Если что-то выглядит не так или не работает, пришлите
> скриншот и текст из `nova.log` — я исправлю.

## Быстрый старт

Нужен Windows 10/11 и Python 3.12 или новее.

```bat
cd NOVA
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Параметр `--minimized` запускает NOVA сразу в трее (так её запускает автозапуск Windows).

## Сборка в один EXE

```bat
build\build_exe.bat
```

Скрипт ставит зависимости, при необходимости генерирует иконку и запускает PyInstaller. Результат: `dist\NOVA.exe`.
Сборка делается только на Windows (PyInstaller собирает под ту систему, на которой запущен).
Если EXE запускается, но музыка или громкость не работают — значит PyInstaller не подтянул часть пакетов
(`winrt`, `pycaw`); см. раздел «Если что-то не работает».

## Что нового в этапе 2

**Игры и приложения** (страницы «Игры» и «Приложения»)
- **Автопоиск** («Найти автоматически» и при запуске NOVA, можно отключить в Настройках): игры Steam (все папки библиотек, обложки из кэша Steam), Epic Games (включая Fortnite — запускается через Epic Games Launcher), GOG, Minecraft; программы из меню «Пуск» и приложения Microsoft Store. NOVA только читает файлы и реестр.
- **Список программ без мусора.** Служебные ярлыки (удаление, справка, сайты, обновления, папка Windows) и предустановленная реклама Store в список не попадают, а ранее найденное такое при поиске убирается из библиотеки (закреплённое в острове, избранное, запускавшееся и добавленное вами вручную не трогается). Популярные программы — Discord (в т.ч. с ярлыком на Update.exe), Steam, Epic/Battle.net/Ubisoft/EA/GOG-лаунчеры, Chrome, Edge, Firefox, Opera, Brave, Яндекс Браузер, Telegram, Spotify, Viber, WhatsApp, Slack, Zoom, OBS, VS Code, 7-Zip, WinRAR, VLC и др. — находятся и по своим обычным папкам, даже если ярлыка в «Пуске» нет.
- **Ручное добавление**: кнопка «Добавить игру…» / «Добавить программу…» (EXE, ярлык, BAT) или перетаскивание файла в окно. Название берётся из имени файла (меняется в «Изменить…»), значок — из самого файла.
- **Карточка**: значок или обложка, название, источник, звезда «избранное», кнопка **«Запустить»** и меню **«⋯»**: Оптимизация…, Изменить…, В избранное, Закрепить в острове, Показать в проводнике, **Удалить из NOVA…**.
- **Удалить из NOVA** убирает только карточку. Файлы программы на компьютере не удаляются и не изменяются. Найденное автоматически скрывается (автопоиск не вернёт), вернуть можно в «Убранные».
- Страница игры по клику на карточку: большая кнопка «ИГРАТЬ», число запусков, последний запуск, время в игре и история сессий.
- Поиск, фильтры «Все / Избранное / Недавние» и по категориям. Если программа удалена с ПК, карточка помечается «Не найдена на ПК», а не пропадает.

**Режим производительности при запуске игры** (Оптимизация → включить; для отдельной игры — «⋯» → «Оптимизация…»)
- На время игры включается схема питания «Максимальная/Высокая производительность», «Игровой режим» Windows, выключается фоновая запись Xbox Game Bar. В Dynamic Island появляется уведомление.
- После закрытия игры всё возвращается как было. Прежние значения записываются **до** изменений: если NOVA закрыли или ПК выключился во время игры, при следующем запуске настройки вернутся сами. «Выключить сейчас» на странице «Электропитание» возвращает всё, не закрывая игру.
- Приоритет процесса («Выше обычного»/«Высокий») ставится только когда NOVA сама запускает EXE игры. Игры из Steam, Epic и Store запускает их лаунчер — NOVA в их процессы не вмешивается, поэтому античиты не должны возражать.
- Для отдельной игры: высокопроизводительная видеокарта и отключение полноэкранных оптимизаций (настройки Windows для конкретного EXE) и список фоновых программ, которые можно закрыть вручную.

**Электропитание**: список схем Windows, «Сделать активной», добавить (копия любой схемы, в том числе «Максимальная производительность»), переименовать, удалить (активную и последнюю удалить нельзя), параметры схемы: минимальное/максимальное состояние процессора, выключение дисплея и сон (питание от сети). Выбор схемы для режима производительности.

**Оптимизация**: настройки режима производительности, безопасные настройки Windows (игровой режим, фоновая запись, прозрачность) с возвратом исходных значений, закрытие выбранных фоновых программ, очистка временных файлов (только после проверки и подтверждения), проверка и очистка старых кэшей шейдеров DirectX/NVIDIA/AMD/Intel (только файлы старше 14 дней, только после подтверждения), быстрые ссылки на системные настройки графики, игрового режима, записи и питания. Очистка кэша шейдеров не гарантирует прирост FPS; после неё игры могут временно пересобирать шейдеры.

**Dynamic Island → вкладка «Приложения»**: плитки ваших программ и игр, которые открываются одним кликом (после клика остров сворачивается). Добавить можно несколькими способами: перетащить EXE или ярлык на раскрытую капсулу; плитка «+» (открывает настройки острова); «Dynamic Island → Быстрый запуск» в окне (из библиотеки или кнопкой «Добавить EXE…»); а также пункт «Закрепить в острове» в меню «⋯» карточки. До 10 плиток, порядок меняется кнопками ↑/↓. Переключение вкладок — колесом мыши или точками справа.

## Что умеет этап 1

**Главное окно**
- Главная: приветствие, дата и время, кольца загрузки CPU / GPU / RAM, график за 2 минуты, время работы ПК, недавние игры и избранные приложения (из БД).
- Мониторинг ПК: CPU (загрузка, потоки, частота, температура), GPU (загрузка, температура, видеопамять, модель), RAM, диски, сеть (загрузка/отдача) — графики в реальном времени. Диски читаются в фоновом потоке.
- Dynamic Island: все настройки капсулы и кнопки проверки.
- Автоматизация: автозапуск вместе с Windows (запись в `HKCU\...\Run`, права администратора не нужны).
- Настройки: светлая/тёмная тема, акцентный цвет (7 готовых + свой), прозрачность окна, анимации, имя в приветствии, сворачивание в трей, сброс настроек.
- Настройки и положение окна сохраняются в SQLite и переживают перезапуск.

**Dynamic Island**
- Отдельное безрамочное прозрачное окно поверх остальных. Клик — раскрыть; правая кнопка или клик по пустому месту раскрытой капсулы — свернуть; колесо мыши и точки справа переключают музыку и статистику.
- Музыка (Spotify, браузеры, другие плееры) через Windows Media Session: название, исполнитель, обложка, прогресс, пауза, следующий/предыдущий трек, анимированные полоски. Когда музыка не играет, блок исчезает.
- Свёрнутый вид: CPU, GPU, RAM, температуры, интернет, часы — что выбрано в настройках. Нет датчика — показывается `N/A`, а не выдуманное число.
- Уведомления: USB, громкость, запуск приложений, смена трека.
- Игровой режим: в полноэкранной игре капсула сама прячется и возвращается после выхода. NOVA только читает размеры и состояние окон — ничего не внедряет в процессы игр, не перехватывает клавиши и не рисует поверх игры.

**Выпиление** (новая вкладка в боковом меню) — все программы Windows в одном списке и их удаление
- В списке: классические программы (раздел «Установка и удаление» реестра: для всех пользователей и только для вас) и приложения Microsoft Store, **включая встроенные от Microsoft** (Новости, Погода, Xbox, Cortana, Teams, Clipchamp, Почта и т.д.). Обновления Windows (KB…) не показываются — они удаляются иначе. У каждой строки: значок, издатель, размер, версия, тип и оценка.
- Фильтры: «Все / Классические / Microsoft Store / От Microsoft / Можно удалять / Осторожно», поиск, сортировка по любому столбцу. Галочка «Показывать системные компоненты и то, что Windows не даёт удалить» открывает остальное (серым — то, что удалить нельзя).
- Оценка — подсказка: **«Можно удалять»**; **«Осторожно»** (библиотеки Visual C++ и .NET, WebView2, драйверы видеокарты/звука/сети, DirectX, античит, антивирус, Microsoft Store, Xbox-службы, OneDrive, Steam — при его удалении может пропасть папка с играми); **«Системное»** (библиотеки Store, скрытые компоненты). Причина — во всплывающей подсказке строки.
- Кнопки «Отметить всё безопасное», «Отметить всё показанное», «Снять отметки». Удаляется только то, что отмечено **и** видно при текущем фильтре.
- **Подтверждение**: окно со списком; точка восстановления Windows (по умолчанию включена; нужны права администратора, при отказе или ошибке NOVA спросит, продолжать ли без неё); для «Осторожно/Системное» — отдельная галочка «понимаю риск»; если выбрано больше пяти программ или есть рискованные — надо ввести слово «УДАЛИТЬ».
- **Как удаляется**: ровно теми командами, которые использует сама Windows: `UninstallString` из реестра (тихо, если у программы есть `QuietUninstallString`), `msiexec /x {GUID}` для MSI, `Remove-AppxPackage` для Store. Окно хода работы с журналом; «Остановить» дожидается окончания текущего удаления и пропускает остальные (процесс удаления NOVA не убивает — прерванное удаление хуже долгого).
- **Результат проверяется по системе**, а не по коду завершения: программа считается удалённой, только если запись исчезла из реестра (или пакет Store пропал из списка Windows). Иначе в журнале будет «не удалось» с причиной. Отказ в окне UAC учитывается отдельно.
- Окно программы удаления у многих программ своё и может запросить подтверждение или права администратора — это нормально. Чтобы не отвечать на UAC для каждой программы, запустите NOVA от имени администратора.

## Честные ограничения

- **Выпиление.** Что Windows сама защищает (`NonRemovable` у Store-компонентов, `NoRemove` у классических — например, часть компонентов Windows, Microsoft Edge, «Безопасность Windows»), NOVA **не обходит**: это показывается серым с причиной. Принудительное удаление такого ломает систему и не гарантируется. Store-приложения удаляются для вашей учётной записи; Windows может вернуть встроенные после крупного обновления или для нового пользователя. Точка восстановления откатывает классические программы и реестр, но не Store-приложения и не ваши файлы; Windows создаёт точки не чаще раза в сутки. Удалённое возвращается только переустановкой. Данные программ в ваших папках NOVA сама не удаляет, но удаление самой программы может убрать её данные (особенно у Steam — сначала сделайте копию игр).

- **Температуры.** Windows не отдаёт температуру CPU штатно. Для неё (и для видеокарт не от NVIDIA) запустите
  [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) от имени администратора и включите
  *Options → Remote Web Server → Run* (порт 8085). NOVA читает данные только с `localhost`. Без него будет `N/A`.
  Для NVIDIA загрузка, температура и видеопамять берутся через NVML (`nvidia-ml-py`) без LibreHardwareMonitor.
- **Системные уведомления Windows** (тосты других программ) пока не перехватываются: Windows требует для этого
  отдельного разрешения. Остров показывает свои уведомления (USB, громкость, запуск приложений, музыка).
- **Эксклюзивный полноэкранный режим.** Остров — обычное окно «поверх остальных». Игры в эксклюзивном полноэкранном
  режиме могут быть выше любого окна; на такой случай и сделано автоскрытие.
- Личные данные, настройки и библиотека не отправляются на серверы NOVA. Каталог «Установить программы» обращается к официальным серверам разработчиков только для загрузки выбранного установщика; мониторинг датчиков использует `localhost` для LibreHardwareMonitor.

**Про оптимизацию и FPS (этап 2)**
- NOVA не обещает «+N FPS». Режим производительности убирает помехи: энергосбережение процессора, фоновую запись, помехи от других программ. Если игру ограничивает видеокарта, прироста может не быть вообще. Эффект зависит от ПК и игры.
- Нет «очистки оперативной памяти», отключения служб, правок реестра с правами администратора и разгона: такие приёмы либо бесполезны, либо рискованны.
- **Для игр из Steam/Epic/GOG** NOVA запускает их через лаунчер (так надёжнее для античитов). EXE игры в Steam определяется эвристикой (самый подходящий файл в папке); если режим не включился, потому что NOVA «не увидела» процесс, укажите EXE в «Изменить» или имя процесса в «Оптимизация…».
- Время в игре считает только запуски из NOVA и только пока она видит процесс. Если NOVA закрыта, время не копится.
- Режим производительности выключается при выходе из NOVA. Чтобы схема питания осталась изменённой, сделайте её активной вручную на странице «Электропитание».
- Для Minecraft, GOG, UWP-приложений и части ярлыков значок может быть стандартным, а не обложкой — обложек у них нет в локальных файлах.
- Команды `powercfg` могут потребовать права администратора на некоторых ПК (например, при корпоративных политиках). Тогда NOVA покажет текст ошибки, а не будет делать вид, что всё получилось.

## Если что-то не работает

Лог лежит в `%APPDATA%\NOVA\nova.log` (кнопка «Открыть папку» в Настройках → Данные).

| Симптом | Что проверить |
|---|---|
| Нет музыки в острове | `pip install winrt-runtime winrt-Windows.Media.Control winrt-Windows.Storage.Streams winrt-Windows.Foundation winrt-Windows.Foundation.Collections`; статус виден в Настройках Dynamic Island → «Проверка» |
| Нет уведомления о громкости | `pip install pycaw comtypes` |
| GPU показывает N/A | Видеокарта не NVIDIA или нет драйвера — запустите LibreHardwareMonitor (см. выше) |
| EXE не видит музыку/громкость | Пересоберите, убедившись, что `build_exe.bat` отработал без ошибок; при необходимости добавьте `--collect-all winrt` в команду PyInstaller |

## Вкладки NOVA 1.05.7

- **Главная** — сводка загрузки CPU / GPU / RAM, график, время работы ПК, недавние игры и избранные приложения.
- **Игры** — библиотека игр и их запуск из NOVA.
- **Приложения** — библиотека установленных программ и быстрый запуск.
- **Центр приложений** — 16 программ в пяти группах: игровые лаунчеры, музыка, браузеры, общение и утилиты. Prism Launcher загружается с официального GitHub-релиза; Minecraft Launcher — Windows Legacy — официальный MSI от Mojang и находится в группе игровых лаунчеров. Для авторизованной сетевой игры нужна лицензированная учётная запись Minecraft. Сторонний Legacy Launcher не добавлен: NOVA не распространяет неофициальные лаунчеры, которые могут обходить проверку аккаунта или владения игрой. Удалены Playnite и Everything, а также все ранее перечисленные пользователем приложения. WinRAR заменяет 7-Zip; PowerToys отсутствует. Прямые установщики загружаются в `Загрузки\NOVA Installers`, проверяется формат EXE/MSI, затем запускается найденный установщик. Rockstar скачивается с CDN Rockstar; если CDN отклонит запрос, NOVA откроет официальную страницу поддержки. Для SoundCloud используется официальный Desktop Player как PWA в Chrome, Brave или Edge — отдельного современного EXE у сервиса нет.
- **Электропитание** — планы питания и настройки энергопотребления Windows.
- **Оптимизация** — режим производительности, обратимые настройки Windows, управление фоновыми программами, очистка временных файлов и старого кэша шейдеров с подтверждением, быстрые ссылки на параметры графики и питания.
- **Выпиление** — список установленных классических и Store-приложений с проверками и подтверждениями перед удалением.
- **Мониторинг ПК** — графики CPU, GPU, памяти, сети и дисков.
- **Процессы** — просмотр активных процессов, PID, загрузки CPU и использования памяти. Вкладка не завершает процессы и не меняет их приоритет.
- **Инструменты Windows** — быстрый доступ к Диспетчеру задач, Диспетчеру устройств, службам, журналам событий, управлению дисками и системным настройкам.
- **О системе** — версия Windows, модель процессора, ядра / потоки, оперативная память и состояние дисков.
- **Dynamic Island** — внешний вид островка, метрики, уведомления и поведение в полноэкранных играх.
- **Автоматизация** — автозапуск NOVA и управление пользовательскими программами в автозагрузке.
- **Настройки** — оформление, анимации, уведомления, поведение окна, данные и страница «О программе».

Страница «О программе» намеренно сделана краткой: название, версия и сведения об авторе проекта — без длинной рекламной справки.

## NOVA 1.05.8 — обязательные обновления

- **Расширенная статистика FPS** — FPS, средний FPS, 1% Low, 0.1% Low, frametime и количество длинных кадров. Сбор выполняется PresentMon без Xbox Game Bar.

- **Network Monitor** — ping, процент потерь, входящий/исходящий трафик и история задержки.
- **NOVA Auto Update** — HTTPS `latest.json`, SHA-256 проверка установщика и запуск Inno Setup после подтверждения пользователем. При доступном обновлении NOVA показывает уведомление.

### Сборка EXE и Inno Setup

Требуется Windows 10/11 x64, Python 3.13 x64 и Inno Setup 6.

**Самый простой вариант:** запусти `build_installer.bat` из корня проекта. Скрипт соберёт `dist\NOVA.exe`, синхронизирует номер версии из `config.py`, скомпилирует `installer\NOVA.iss` и сохранит результат в `release\`.

**Через Inno Setup Compiler вручную:**
1. Запусти `build\build_exe.bat`.
2. Выполни `powershell -ExecutionPolicy Bypass -File build\sync_version.ps1`.
3. Открой `installer\NOVA.iss` в Inno Setup Compiler.
4. Нажми **Build → Compile** или F9. Результат будет в `release\NOVA_Setup_[версия].exe`.

### Как выпускать обновления для всех пользователей

1. Создай публичный GitHub-репозиторий и загрузи туда исходники NOVA.
2. В `config.py` замени `r1zorichgg-droi/NOVA` в `UPDATE_MANIFEST_URL` на `username/название-репозитория`. В `installer\NOVA.iss` также замени ссылки `r1zorichgg-droi/NOVA` на свой репозиторий.
3. Увеличивай только `APP_VERSION` в `config.py` (например, `1.05.6` → `1.05.7`). `build\sync_version.ps1` автоматически переносит версию в `installer\version.iss`.
4. Отправь изменения в GitHub и создай тег с такой же версией: `git tag v1.05.7`, затем `git push origin main --tags`.
5. GitHub Actions соберёт приложение и установщик на Windows, посчитает SHA-256 и опубликует `latest.json` вместе с GitHub Release.
6. У всех пользователей, установивших сборку с этим `UPDATE_MANIFEST_URL`, проверка выполняется при запуске NOVA. Когда выйдет новая версия, появится уведомление; пользователь сможет открыть вкладку «Обновления NOVA» и подтвердить установку.

Все версии должны использовать один и тот же `AppId` в `installer\NOVA.iss`. Папку пользовательских данных `%APPDATA%\NOVA` установщик не удаляет, поэтому настройки, профили и история FPS сохраняются. Подробнее — `AUTO_UPDATE.md`.

**Важно:** у старых выпусков NOVA, в которых ещё нет страницы автообновления, нет механизма для самостоятельного получения этого обновления. Их пользователям сначала нужно вручную установить NOVA 1.05.8. После этого будущие версии будут находиться через общий GitHub-канал. Для реальной публикации нужно заменить шаблон `r1zorichgg-droi/NOVA` и создать собственный публичный GitHub-репозиторий. Сам Windows EXE/установщик должен собираться на Windows или Windows runner GitHub Actions — текущая среда Linux не может проверить их запуск.
