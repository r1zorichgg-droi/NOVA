NOVA 1.05.8 — сборка Windows EXE и Inno Setup

Быстрая сборка:
1. Установи Python 3.13 x64 и Inno Setup 6.
2. Запусти build_installer.bat.
3. Готовые NOVA.exe, NOVA_Setup_[APP_VERSION].exe и latest.json появятся в release\.

Будущие релизы:
1. Измени APP_VERSION в config.py.
2. В GitHub Desktop создай коммит, Summary которого начинается с "release:", например "release: NOVA 1.05.9".
3. Нажми Push origin.
4. GitHub Actions автоматически создаст Windows-сборку и GitHub Release.

Обновления:
- Автоматическая проверка при старте и каждый час.
- При обнаружении новой версии установщик скачивается автоматически и проверяется по SHA-256.
- Пользователь должен установить обновление или выйти из NOVA.
- NOVA не может обновить выключенный компьютер мгновенно: проверка будет при следующем запуске.
- В установщике запуск NOVA вместе с Windows выбран по умолчанию, чтобы проверка работала после входа.
- Пользователям 1.05.7 потребуется один раз установить 1.05.8 вручную.

Не меняй AppId в installer\NOVA.iss. Пользовательские данные находятся в %APPDATA%\NOVA.
