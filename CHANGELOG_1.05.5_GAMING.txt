NOVA 1.05.5 — Launchers, FPS & Logo Update

Центр приложений
- Каталог выровнен до 16 программ в пяти категориях.
- Prism Launcher перемещён в «Игровые платформы» и скачивается по прямой ссылке из официального GitHub-релиза.
- Minecraft Launcher — Windows Legacy (Mojang) добавлен в категорию игровых лаунчеров; ссылка ведёт на официальный MSI с minecraft.net.
- Rockstar Games Launcher скачивается напрямую с CDN Rockstar. При отказе CDN NOVA открывает официальную страницу загрузки Rockstar.
- Для прямых загрузок добавлены стандартные HTTP-заголовки браузера и увеличенный timeout.
- SoundCloud открывается как официальный Desktop Player PWA через Chrome, Brave или Edge; отдельный актуальный EXE не заявлен разработчиком.
- Удалены Playnite и Everything. WinRAR остаётся вместо 7-Zip.
- Третий сторонний Legacy Launcher/TLauncher не включён; добавлен официальный Windows Legacy Launcher от Mojang вместо них.

Брендинг
- Пользовательская иконка NOVA применена к nova.png и nova.ico.
- Иконка используется главным окном, боковой панелью, треем, установщиком и страницей «О программе».
- В App Hub вместо буквы N показывается новый логотип.
- Сайт «О программе» обновлён; убраны устаревшие упоминания Playnite и Everything.

FPS
- Вкладка «Игры» содержит встроенную панель FPS на PresentMon.
- Показываются текущий FPS, средний FPS и 1% Low.
- Есть кнопки включения/выключения счётчика и показа/скрытия оверлея.
- Оверлей запускается заблокированным; его можно разблокировать, перетащить и снова заблокировать.
- Положение сохраняется, в заблокированном режиме окно прозрачно для мыши, чтобы клики проходили в игру.
- PresentMon загружается при первом запуске FPS и проверяется по SHA-256; Xbox Game Bar не используется.

Проверка
- 213 автоматических тестов прошли.
- Python compileall прошёл без ошибок.
- В этой среде PySide6 и Windows нет, поэтому реальная отрисовка Qt, прямые сетевые загрузки,
  запуск установщиков и захват кадров должны быть дополнительно проверены на Windows 10/11.
- Архив содержит исходный проект и скрипты сборки, но не готовые Windows EXE.
